# Robot — Unreal Engine 5 C++ Project

A third-person gameplay project developed in Unreal Engine 5 using C++.

This repository showcases my ongoing work as I develop my Unreal Engine C++ programming skills and build gameplay systems.

## Project Focus

- Character movement and player controls
- Third-person camera implementation
- Character animation integration
- Gameplay programming with Unreal Engine C++
- Object-oriented design and component-based architecture

## Technologies

- Unreal Engine 5
- C++
- Unreal Engine Gameplay Framework
- Visual Studio
- Git

## Repository Contents

`Source/` — C++ gameplay implementation

`Config/` — Unreal Engine project configuration

`Robot.uproject` — Unreal Engine project descriptor

## Important Note

This is a source-code showcase intended for code review. Game assets and third-party content are not included, so this repository is not a complete playable build.

Active development. Systems and architecture are being continuously improved.
